# 角色参考图提示词指南

用豆包生成角色六视图设定图与道具特写图时的提示词工程。

## 六视图提示词模板

固定结构，缺一不可：

```
[画风] + 角色设定图，六视图并排（character turnaround sheet）：
角色名：[name]
外形：[desc]
六个角度：正面全身、背面全身、左侧面全身、右侧面全身、3/4前视全身、3/4后视全身
六个角度必须是同一个人物，五官、发型、服装、体型、配饰完全一致
白底参考图风格，角色居中站立，中性T-pose或自然垂手站姿
[画质约束]
```

### 画风前缀（与漫剧 split_novel.py 的 STYLE_PRESETS 一致）

| key | 前缀 |
|-----|------|
| `3d-realistic` | CG写实3D风格，计算机生成（CGI），UE5电影级实时渲染，3D建模的仿真数字人，真人比例与真实人体解剖结构，PBR材质，细腻真实的皮肤质感与毛孔细节，次表面散射，真实毛发与布料模拟，电影级物理光照与全局光照；非真人实拍，非卡通，非动漫 |
| `3d-cartoon` | 3D动画电影风格，皮克斯式卡通渲染，角色为大眼圆润的卡通造型，柔和次表面散射光照，色彩明快饱和 |
| `cinematic` | 写实电影质感，真人实拍风格，电影级布光与调色，浅景深，35mm胶片颗粒感，高细节皮肤与材质 |
| `guoman-2d` | 国漫二维动画风格，赛璐璐上色，线条清晰凌厉，中国风美术设计 |
| `anime` | 日式动漫风格，新赛璐璐作画，线条干净通透，明亮高饱和色彩 |
| `ink-wash` | 中国水墨动画风格，写意留白，宣纸质感，墨色浓淡变化 |

## 角色描述写作要点

角色参考图的成败 90% 取决于外形描述质量。

### 必须写明的五维度

1. **年龄 + 性别**："三十岁男性" / "二十五岁女性"
2. **面部骨相**：颧骨/下颌线/眉形/眼形/鼻型——写骨相而非"帅/美"
3. **发型发色**：长度 + 形状 + 颜色——"短寸黑发" / "长发及腰微卷"
4. **服装**：款式 + 颜色 + 材质 + 层次——"深灰色立领长风衣"
5. **体型**：修长/壮硕/纤细/圆润

### 好描述 vs 坏描述

| 维度 | ✅ 好 | ❌ 坏 |
|------|-------|------|
| 面部 | "颧骨分明，下颌线硬朗，剑眉星眸" | "英俊帅气" |
| 发型 | "短寸黑发，鬓角剃青" | "发型很酷" |
| 服装 | "深灰色立领长风衣，内搭黑色高领毛衣" | "穿着时尚" |
| 体型 | "修长挺拔，肩宽腰窄" | "身材好" |
| 配饰 | "腰悬半月形白玉佩，穿红丝穗" | "带着饰品" |

### CG 写实 3D 专项（`3d-realistic`）

CG 写实对"人味"要求最高，三处必须到位：

1. **双向反向约束**：画风前缀必须带「非真人实拍，非卡通，非动漫」——防被识别为 `cinematic` 或回落卡通
2. **写实骨相词汇**：写「颧骨分明」「下颌线硬朗」而非「大眼」「圆润」
3. **渲染词汇**：「PBR 材质」「次表面散射」「光线追踪」优于「明快饱和」「卡通渲染」

## 调优路径

参考图效果不好时按此顺序排查：

1. **六视图角度不全** → 提示词里显式列出六个角度名，强调"六个角度并排"
2. **六角度人物不一致** → 强化「六个角度必须是同一个人物，五官发型服装完全一致」
3. **风格不对** → 换 `--style` 预设重生成，而非手动改词
4. **角色脸崩** → 缩短描述中的修饰词数量，保留核心骨相特征
5. **道具太小看不清** → 提示词加"特写""放大""居中"

每次只改一个变量。
